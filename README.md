Global Fuel Prices and Taxation Trends

Project Overview

This project analyzes global fuel prices and taxation trends using data analytics and Tableau visualizations.

Objectives

- Analyze fuel price trends over time.
- Compare fuel prices across countries and regions.
- Explore taxation and subsidy patterns.
- Create interactive charts and a dashboard.
- Present insights for energy policy, logistics, and economic research.

Tools Used

- Tableau Public
- Microsoft Excel or Google Sheets
- GitHub

Planned Visualizations

1. Global fuel price map
2. Fuel price trends over time
3. Regional price comparison
4. Taxation versus fuel prices
5. Country price rankings

Project Files

- "data/": Dataset files
